03 · Concepto

MCP, el USB-C de los modelos.

Model Context Protocol. Estándar abierto. Cualquier herramienta puede "enchufarse" al modelo.

Tres piezas. Host: la app donde trabajas (VS Code). Cliente MCP: vive dentro, habla el protocolo. Servidor MCP: lo publica cada herramienta (Atlassian, Figma…).

El servidor expone tools (acciones), resources (datos) y prompts (plantillas). Estándar abierto, no propietario.

04 · Capacidades reales

Lo que puedo y lo que no con MCP.

Tres herramientas conectadas hoy. Lectura va de sobra; escritura, con matices; admin, casi nada. El alcance importa más que la teoría.

JR Jira (Atlassian)
✓ puedo
  • Lectura: issues, JQL, proyectos, metadatos, tipos
  • Escritura: crear/editar issues, comentar, worklogs, links, cambiar estado
✕ no puedo
  • Xray: sin crear/editar tests (import JSON bulk manual)
  • Adjuntos: sin subir ni descargar
  • Admin: sin proyectos, usuarios ni permisos
  • Automatizaciones: sin reglas
  • Sprints / tableros: sin gestión
  • Bitbucket: sin acceso a código
CF Confluence (Atlassian)
✓ puedo
  • Lectura: páginas, espacios, comentarios, CQL
  • Escritura: crear y actualizar páginas, comentarios
✕ no puedo
  • Adjuntos: sin subida/descarga
  • Admin de espacios: sin gestión
  • Permisos: sin tocar accesos
Figma
✓ puedo
  • Lectura: componentes, screenshots, metadatos
  • Variables / tokens del archivo
  • FigJam: leer tableros
  • Code Connect: mappings Figma ↔ código
  • Generación: diagramas FigJam, diseños
✕ no puedo
  • Editar diseños existentes (capas, estilos)
  • Subir assets o imágenes
  • Permisos de archivos/proyectos
  • Prototipados o flujos interactivos
  • Equipos / orgs: sin gestión
# Lo que puedo y lo que no con MCP

## Jira (Atlassian)
**✓ Puedo**
- Lectura: issues, JQL, proyectos, metadatos
- Escritura: crear/editar issues, comentar, worklogs, links, estado

**✕ No puedo**
- Xray: crear/editar tests (import JSON manual)
- Adjuntos, admin Jira, automatizaciones, sprints, Bitbucket

## Confluence (Atlassian)
**✓ Puedo**
- Lectura: páginas, espacios, comentarios, CQL
- Escritura: crear y actualizar páginas + comentarios

**✕ No puedo**
- Adjuntos, admin de espacios, permisos

## Figma
**✓ Puedo**
- Lectura: componentes, screenshots, metadatos
- Variables/tokens, FigJam, Code Connect, generación

**✕ No puedo**
- Editar diseños, subir assets, permisos, prototipos, equipos
